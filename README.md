# Бот важных новостей для Telegram

Бесплатный бот: никаких платных API и ключей. Он публикует в канал только крупные события, а если важного нет, ничего не пишет.

## Как он работает

1. Каждые 30 минут бот скачивает RSS-ленты ~16 российских изданий из `feeds.txt`: ТАСС, РИА, Интерфакс, Коммерсантъ, РБК, Лента, Известия и др.
2. Заголовки за последние 6 часов он группирует в сюжеты по общим словам.
3. **Первый фильтр — сколько изданий пишут о сюжете.** Сюжеты, которые подхватили 3+ разных издания, идут дальше. Мелочь отсеивается сразу.
4. **Второй фильтр — локальная нейросеть** (Ollama, модель `qwen2.5:3b`). Она пропускает только новости, без знания которых жителю России будет хуже. Для этого она отвечает на три вопроса:
   - **Касается ли это лично почти каждого?** Его денег, цен, налогов, работы, документов, поездок, связи, безопасности, прав. Новости одного региона, отрасли или другой страны не проходят.
   - **Требует ли это внимания?** Нужно ли что-то сделать, подготовиться или изменить планы. Заявления, переговоры, прогнозы, происшествия, спорт и шоу-бизнес не проходят, даже если о них пишут все.
   - **Это уже свершившийся факт?** Законопроекты, предложения и слухи не проходят.

   Публикуется только то, где все три ответа «да». Поэтому канал **молчит почти всегда**, это нормально.
5. К новости нейросеть пишет короткий пересказ и строку «Что это значит» — чем событие важно для обычного человека. Под текстом ставятся ссылки на источники.
6. Каждый сюжет выходит один раз. Отклонённый сюжет нейросеть оценит повторно, только если о нём начнут писать заметно больше изданий.

Если нейросеть временно не отвечает, бот ничего не публикует и пробует снова при следующей проверке. Без нейросети (запуск без Docker) бот работает по простому правилу: публикует сюжеты, о которых пишут 5+ изданий.

## Подготовка

1. **Создайте бота.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и сохраните токен.
2. **Добавьте бота в канал** администратором с правом публиковать сообщения.
3. **Скачайте проект и создайте файл настроек:**
   ```bash
   git clone https://github.com/pinokkkio/news.git
   cd news
   cp .env.example .env
   ```
   Откройте `.env` и впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHANNEL_ID` (`@имя_канала`).

## Запуск в Docker (рекомендуется)

Нужен [Docker](https://docs.docker.com/get-docker/), а на Windows и macOS — Docker Desktop. Машине нужно **~4 ГБ свободной памяти** и **~3 ГБ на диске** под модель.

Всё делается скриптом `run.sh`. На Windows запускайте его из Git Bash или WSL.

```bash
./run.sh test      # 1. проверить нейросеть на тестовых новостях
./run.sh feeds     # 2. проверить, какие ленты доступны
./run.sh preview   # 3. посмотреть текущие главные сюжеты и пример поста — без публикации
./run.sh start     # 4. запустить бота в фоне
./run.sh logs      #    следить за работой (Ctrl+C — выйти из логов)
./run.sh restart   #    применить изменения .env / feeds.txt
./run.sh stop      #    остановить
```

При первом запуске скрипт создаст `.env` и попросит вписать в него токен и канал. Первая команда скачивает нейросеть (~2 ГБ), это займёт несколько минут. После `start` бот работает сам: проверяет новости каждые 30 минут и перезапускается после перезагрузки компьютера, пока запущен Docker.

`./run.sh test` прогоняет через модель 12 выдуманных сюжетов с известным правильным ответом: мобилизация, обвал рубля и блокировка WhatsApp должны пройти, а законопроект о VPN, прогноз цен на бензин, отключение воды в одном городе, Лавров, Песков, спорт и свадьба певицы — нет. По каждому сюжету скрипт показывает решение модели, её ответы на три вопроса и пересказ. Если верных решений меньше 10 из 12, поставьте в `.env` модель помощнее: `OLLAMA_MODEL=qwen2.5:7b`.

## Запуск без Docker

Работает без нейросети: бот публикует заголовки и описания из лент. Нужен Python 3.9+.
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py --dry-run     # проверить
.venv/bin/python bot.py --loop        # работать постоянно (или запускать bot.py через cron)
```
Чтобы подключить нейросеть, установите [Ollama](https://ollama.com) и добавьте в `.env` строку `OLLAMA_URL=http://localhost:11434`.

## Настройки (`.env`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `MIN_SOURCES` | 3 (без нейросети 5) | Сколько изданий должно написать о событии, чтобы его оценивать |
| `INTERVAL_MINUTES` | 30 | Как часто проверять новости |
| `WINDOW_HOURS` | 6 | За какой период сравниваются новости |
| `MAX_POSTS` | 3 | Максимум постов за одну проверку |
| `OLLAMA_MODEL` | qwen2.5:3b | Модель для пересказа. `qwen2.5:7b` пишет лучше, но нужно ~8 ГБ RAM |

Список изданий хранится в `feeds.txt`, по одной RSS-ссылке в строке. Все ленты должны быть на русском языке.
