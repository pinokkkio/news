# Бот важных новостей для Telegram

Бесплатный бот без нейросетей и платных API. Он публикует в канал только крупные события, а если важного нет, ничего не пишет.

## Как он решает, что важно

**Важная новость — та, о которой одновременно пишут многие независимые редакции.** Мелкую новость подхватывают одно-два издания, а о землетрясении, решении ЦБ или громкой отставке пишут все.

При каждом запуске бот:
1. Скачивает RSS-ленты примерно 15 изданий из `feeds.txt`: ТАСС, РИА, Интерфакс, Коммерсантъ, РБК, Лента, Известия и др.
2. Группирует заголовки за последние 6 часов в сюжеты по общим словам. Например, «Землетрясение магнитудой 7,8 у берегов Японии» и «Японию накрыло мощное землетрясение» попадут в один сюжет. Редкие слова (*землетрясение*, фамилии) при сравнении весят больше частых (*Россия*).
3. Публикует сюжет, если о нём написали **5+ разных источников**. Каждый сюжет выходит один раз.

Пост состоит из заголовка, краткого описания и ссылок на источники.

## Настройка (один раз)

1. **Создайте бота.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и скопируйте токен.
2. **Добавьте бота в канал** администратором с правом публиковать сообщения.
3. **Установите бота** (нужен Python 3.9+):
   ```bash
   git clone <этот репозиторий> news && cd news
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   cp .env.example .env      # впишите токен бота и канал
   ```
   `TELEGRAM_CHANNEL_ID` — это `@имя_канала` или числовой id вида `-100…` для приватного канала.
4. **Проверьте ленты:** `.venv/bin/python bot.py --check-feeds`. Неработающие ленты удалите из `feeds.txt` или замените.
5. **Посмотрите, что сейчас в топе:** `.venv/bin/python bot.py --dry-run`. Команда покажет крупнейшие сюжеты и число источников у каждого. Ничего не публикуется.

## Запуск по расписанию

**Linux/macOS (cron).** Выполните `crontab -e` и добавьте строку, чтобы бот запускался каждые 30 минут:
```
*/30 * * * * cd /путь/к/news && .venv/bin/python bot.py >> bot.log 2>&1
```

**Windows.** В «Планировщике заданий» создайте задачу с повтором каждые 30 минут:
программа `C:\путь\к\news\.venv\Scripts\python.exe`, аргументы `bot.py`, рабочая папка `C:\путь\к\news`.

## Настройки (в `.env`)

- `MIN_SOURCES=5`: сколько источников должно написать о событии. **Главная ручка.** Если постов много, увеличьте порог, если мало — уменьшите. Подобрать значение помогает `--dry-run`.
- `WINDOW_HOURS=6`: за какой период сравниваются новости.
- `MAX_POSTS=3`: максимум постов за один запуск.

В `feeds.txt` можно добавлять свои ленты. Все они должны быть на одном языке, потому что бот сравнивает слова заголовков. Несколько лент одного сайта считаются одним источником.

Бот хранит собранные заголовки и опубликованные сюжеты в `state.json`. Удалите этот файл, чтобы начать с чистого листа.
