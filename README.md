# Бот важных новостей для Telegram

При каждом запуске бот собирает свежие заголовки из RSS-лент (`feeds.txt`). Затем Claude отбирает из них только действительно важные новости, и бот публикует их в ваш канал. Если важного нет, бот ничего не пишет. Бот не работает постоянно: он делает один проход и завершается, поэтому его запускают по расписанию.

## Настройка (один раз)

1. **Создайте бота.** Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и скопируйте токен.
2. **Добавьте бота в канал** администратором с правом публиковать сообщения.
3. **Получите ключ Claude API** на https://platform.claude.com (раздел API Keys).
4. **Установите бота** (нужен Python 3.10+):
   ```bash
   git clone <этот репозиторий> news && cd news
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   cp .env.example .env      # и впишите в .env токен, канал и ключ
   ```
   `TELEGRAM_CHANNEL_ID` — это `@имя_канала` для публичного канала или числовой id вида `-100…` для приватного.
5. **Проверьте без публикации:**
   ```bash
   .venv/bin/python bot.py --dry-run
   ```
   Бот покажет посты, которые опубликовал бы, но ничего не отправит.

## Запуск по расписанию

**Linux/macOS (cron).** Выполните `crontab -e` и добавьте строку, чтобы бот запускался каждый час:
```
0 * * * * cd /путь/к/news && .venv/bin/python bot.py >> bot.log 2>&1
```

**Windows.** В «Планировщике заданий» создайте задачу с повтором раз в час:
программа `C:\путь\к\news\.venv\Scripts\python.exe`, аргументы `bot.py`, рабочая папка `C:\путь\к\news`.

Если компьютер был выключен, ничего страшного: при следующем запуске бот рассмотрит новости за последние 24 часа, которые ещё не видел.

## Настройки

- `feeds.txt` — список RSS-лент, их можно добавлять и удалять.
- `MIN_IMPORTANCE` в `.env` — порог важности от 1 до 10 (по умолчанию 7). Чем выше порог, тем реже посты.
- `NEWS_LANGUAGE` — язык постов (по умолчанию русский).
- `CLAUDE_MODEL` — модель Claude (по умолчанию `claude-opus-5-5`).

Бот запоминает уже просмотренные и опубликованные новости в `state.json`, поэтому не повторяется. Удалите этот файл, чтобы начать с чистого листа.

Один запуск стоит примерно несколько центов за вызов Claude API: стоимость зависит от числа заголовков.
